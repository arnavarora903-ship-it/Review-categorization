# Review Categorization Tool

## Overview
An LLM-based system that classifies customer reviews into predefined categories and extracts key themes.

## Features
- Classification using structured outputs  
- Keyword and theme extraction  
- Consistent and predictable output formatting  

## Workflow Design
This project follows a structured pipeline:
1. Input processing  
2. Prompt-based classification  
3. Structured output generation  
4. Post-processing for consistency  

## Tech Stack
Python, LangChain
